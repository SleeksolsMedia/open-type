02
The Voicebar Orb
The single most important object in the app. It's a floating overlay bubble that lives on top of every other app (Android system overlay) and inside the custom keyboard (iOS). The mark from our identity — the equalizer caret — sits at its center and is what animates. Everything the user does starts and ends here.
100% size · ink surface, coral mark
Orb — build spec
Component
<VoicebarOrb /> — a draggable overlay rendered by a native Android overlay service, and inside the iOS keyboard extension.
Shape
Perfect circle. Ink surface #1A1714, coral equalizer mark centered. Drop shadow y10 blur26 rgba(26,23,20,.34).
Base size
66 dp diameter at 100%. Mark is ~50% of diameter.
Size steps
User-set in Settings: 70% 85% (default) 100% 115%. Sliders snap to these only.
Opacity
Idle opacity user-set: 20/40/60/80(default)/100%. Returns to 100% the instant it's touched or active.
Position
Free-drag, always snaps to nearest left/right edge. Remembers last position across sessions.
When visible
Only when a text field / on-screen keyboard is focused. Hidden in password, numeric, phone, and blocked (banking) fields.
Why an orb
It must read at a glance over any background, be thumb-reachable one-handed, and never look like part of the host app. The equalizer mark makes its purpose obvious the moment it moves.
03
Orb states
The orb is a small state machine. Each state has a distinct color, motion, and size so the user always knows what's happening without reading text. Coral = your voice. Amber = the LLM is rewriting. These are the exact visual targets for the agent.
DEFAULT
Idle
Resting caret, 80% opacity. Waiting to be held or tapped.
MINIMISED
Shrunk to a dot
After 5s idle (instant in search fields) it collapses to a dot. Tap restores + starts a dictation.
RECORDING
Listening
Bars react to live mic amplitude; a coral ring pulses outward. Grows ~10%.
LLM ENHANCE
Enhancing
Bars morph into a slow amber spark. Only when LLM enhance is on. Skipped otherwise.
DONE
Inserted
Brief green check, then a copy button slides out beside it and auto-dismisses.
PROBLEM
!
Error
Orange badge. Tap opens a card: "Couldn't transcribe — saved in app." Retry / Dismiss.
State machine — transitions
idle → listening
Press-and-hold (push-to-talk) or single tap (hands-free). Light haptic on entry. Ring pulse starts, size +10%.
listening → enhancing
On release (hold) or Done (hands-free). Medium haptic. If LLM enhance is OFF, skip straight to inserted.
enhancing → inserted
Text is placed at the cursor. Success haptic + green check for 600ms, then copy button appears for 4s and auto-dismisses.
any → error
On STT/LLM/network failure. Error haptic. Audio is retained so Retry can reuse it. Never lose the user's words.
idle → dot
After 5000ms of no interaction. Fades opacity + scales to 22dp. Reverses on tap.

Orb gestures
The orb has no menu — everything is a gesture. This is what makes it feel native and out of the way. Implement with react-native-gesture-handler + react-native-reanimated; the timings below are the target feel.
👆

Hold to speak

Press and hold the orb, talk, release to submit. The primary, most-used gesture — like a walkie-talkie.

LongPress · onBegin→record · onEnd→submit
👉

Tap for hands-free

A single tap starts a hands-free session with floating Cancel / Done controls. Tap Done (or the orb) to finish.

Tap · toggles hands-free mode

Drag to move

Drag anywhere; the orb follows your finger, then springs to the nearest side edge and remembers it.

Drag to snooze

Drag down to the snooze zone that appears at the bottom; drop to hide the orb for 10 minutes.

Permissions the orb needs (Android)
Overlay
"Display over other apps" — required to float above other apps. Without it, no orb.
Accessibility
Accessibility Service — used to insert text into the focused field. If revoked, show a repair state that deep-links to settings.
Microphone
Runtime mic permission. Prompt from the main app (an overlay can't show the system dialog).
iOS note
iOS has no floating overlay — ship the orb's brain inside a custom keyboard extension with a mic button + waveform, needing Full Access.
05
The one flow that matters
Raw speech in → your STT model → optional LLM cleanup against your system prompt → clean text at the cursor. This is the whole product. Show the "cleaning up" chips so the user sees the value being added.
01 · CAPTURE
"um so basically i want to like send the report by friday okay the the friday one"
Raw transcript from the user's chosen STT — local model, REST API, or WebSocket stream.
02 · ENHANCE
LLM applies the user's system prompt.
filler removedrepetition fixedpunctuation
Optional. User's own LLM key + system prompt decide tone, format, cleanup rules.
03 · INSERT
"I'll send the report by Friday."
Clean text is typed into whatever field had focus — any app, any input.
Modes the user configures (open-source core)
STT source
Bring your own: ① paste an API endpoint + key, ② connect a live WebSocket, or ③ download an on-device model for fully offline dictation.
LLM enhance
Optional toggle. When on, requires an LLM API key and a user-editable system prompt. When off, raw transcript is inserted (no amber state).
Privacy
Offline model = nothing leaves the phone. Make this visible and reassuring — it's the reason to choose OpenType over closed apps.
